# Linux Student Development Environment

Standard Linux Mint development environment for Skyview Robotics
Tactics & Strategy student development laptops.

## Baseline

The Linux environment will provide the same core student development capabilities
as the Windows environment using native Linux packages and configuration.

Planned baseline:

- Node.js LTS and npm
- Git
- GitHub CLI
- VSCodium
- DBeaver
- Google Chrome
- Mozilla Firefox
- OpenSSH client
- Supporting command-line utilities

The Linux environment will be provisioned with native package-management and
shell scripting rather than Chocolatey.

Ready-to-install packages and release bundles will be published through GitHub Releases.
