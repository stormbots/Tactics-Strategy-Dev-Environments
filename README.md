# Tactics & Strategy Development Environments

Standardized development workstation configuration for the Skyview Robotics
Bureau of Tactics & Strategy subteam.

This repository contains provisioning, configuration, validation, and
maintenance tools for student development laptops.

## Platforms

### Windows 11

Windows-native student development environment using Chocolatey.

See [Windows setup](windows/README.md).

Current release: [Windows Student Dev Environment 1.0.1](https://github.com/stormbots/Tactics-Strategy-Dev-Environments/releases/tag/windows-v1.0.1).

### Linux Mint

Linux Mint Cinnamon student development environment using native Linux package
repositories and shell provisioning.

See [Linux setup](linux/README.md).

Current release: [Linux Mint Student Dev Environment 1.0.1](https://github.com/stormbots/Tactics-Strategy-Dev-Environments/releases/tag/linux-v1.0.1).

## Releases

Ready-to-install packages are distributed through GitHub Releases rather than
stored directly in the repository.

Platform releases are versioned independently:

- `windows-v1.0.1`
- `linux-v1.0.1`
