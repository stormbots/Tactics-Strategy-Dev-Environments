# SDE 1.2.21 — Clearer Recovery for students

Focused UAT candidate for the Recovery-page feedback from v1.2.20.

- Recovery starts with a short explanation and **What to do now**. Unknown
  activity gets save-work, normal Restart and Check again instructions. Active
  work gets wait instructions; unreadable records get support guidance instead
  of a promise that restart will fix them.
- The most useful action is highlighted. **Back to Overview** replaces Cancel
  and still cancels the pending request. Validation is offered only when current
  observations establish inactivity and trusted native coordination.
- **Technical details**, **Earlier recovery events** and **Saved reports** start
  collapsed. Incident references and exact diagnostic findings are still there.
- The acknowledgment reminder appears only for the matching available computer
  incident; it does not cover a separate account incident. Report-save warnings
  remain visible. Sharing is optional; no report uploads automatically.
- Primary Recovery buttons retain readable text in both themes, including normal,
  focus and hover states. The full accessibility checks remain enforced.

This changes presentation, not recovery authority. Acknowledgment still attempts
its summary automatically and preserves original evidence. Activity/trust/package
checks, journal retention, normal confirmations and OS authorization are unchanged.
No automatic repair, process termination, lock deletion or replay was added.

Use the [focused student Recovery UAT sheet](RECOVERY-STUDENT-UAT-1.2.21.md) after
Codex authenticates this candidate and supplies installation instructions. Existing
Windows interruption evidence and Mint v1.2.18 **35/0/0** acceptance are preserved.

Only v1.2.21 is published through the protected workflow after owner signing
approval. Rebuilt same-source v1.2.20 remains an unpublished native upgrade
fixture; published v1.2.20 and older assets are not changed. Application
installation enables automatic SDE updates as before; the tool baseline is
unchanged. No stable promotion, fleet rollout or milestone acceptance is implied.
