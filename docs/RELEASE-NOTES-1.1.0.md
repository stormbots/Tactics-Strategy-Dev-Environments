Skyview Robotics Student Development Environment 1.1.0 — Bureau of Tactics & Strategy.

**Mentor-testing prerelease:** validate on one Windows 11 laptop and one Linux Mint Cinnamon laptop before fleet deployment.

### Windows

Download **Skyview-Dev-Setup-Windows-x64.exe** and open it. Launch Skyview Dev Setup, click Install Development Environment, and approve administrator access when asked.

### Linux Mint

Download **Skyview-Dev-Setup-LinuxMint-amd64.deb**, open it, install it, then launch **Skyview Development Environment Setup**. Click Install Development Environment and approve administrator access when asked.

### What's included

One shared graphical installer with Install, Repair, Validate and Update, real progress, saved logs, graphical validation and the supplied Skyview branding. Existing PowerShell/Chocolatey and Bash/APT provisioning remain the backend. Managed updates retain Node 24.x and Python 3.14.x. Student projects and existing editor settings are preserved. Git identity and GitHub sign-in are left for the student/mentor.

Check **SHA256SUMS.txt** for download integrity. Initial Windows binaries are unsigned; mentor acceptance includes publisher/SmartScreen behavior. Real laptop elevation and package-installation acceptance is pending. The original Windows and Linux v1.0.1 releases remain available as stable fallbacks.
